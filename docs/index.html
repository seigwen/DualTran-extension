常见问题

需要自己准备 API Key 吗？

不需要。默认使用 Google 翻译，装好就能用。想用 AI 翻译时，再填入任意一家服务商的 Key（OpenAI、DeepSeek、通义、Moonshot、OpenRouter、本地 Ollama 都行）。

我的浏览数据会被上传吗？

不会。扩展不收集统计，也没有自建服务器。要翻译的文字只发送给你选择的翻译服务（Google 或你自己的 AI 服务商）。

支持哪些语言？

Google 通道支持 100+ 种语言互译；AI 通道取决于你用的模型。界面已本地化为 38 种语言。

为什么有时候译文是蓝色的？

那是可点击的译文样式，方便你复制或对照。可以在「样式」里改成与正文同色。

能在手机浏览器用吗？

暂时不行。桌面 Chrome / Edge / Firefox 可用；Obsidian 插件覆盖笔记场景。
