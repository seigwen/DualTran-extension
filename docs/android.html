安卓上也能用

安卓的 Chrome 本身不支持扩展，但有四个浏览器支持——其中三个可以直接装 Chrome 商店里的同一个包。

浏览器来源支持程度
Kiwi BrowserGoogle PlayChromium 内核，直接装 Chrome 商店扩展，最省事
Lemur BrowserGoogle Play同上，界面更接近原生
Mises Browser官网 / 应用商店同上，内置扩展商店入口
Firefox for AndroidGoogle Play / 官网官方支持扩展，DualTran 已声明兼容（Firefox 142+）

一、Kiwi / Lemur / Mises（用 Chrome 商店）

1. 在浏览器里打开 Chrome 商店的 DualTran 页
2. 点「添加到 Chrome」→ 确认
3. 打开任意英文网页，右下角会出现悬浮按钮，点它开始翻译

如果商店提示「您的浏览器不受支持」，在浏览器设置里打开「桌面版网站」再试一次——这几个浏览器对商店的 UA 判断不一致。

二、Firefox for Android

1. 打开 AMO 上的 DualTran 页
2. 点「添加到 Firefox」
3. 菜单 → 扩展 → DualTran，确认已启用

Firefox 安卓只允许安装 AMO 上标记为安卓兼容的扩展；DualTran 2.3.0 起已声明 gecko_android，在 Firefox 142 及以上可用。

三、手机上体验会差在哪

  • 屏幕窄：对照式翻译会让页面变长一倍，建议在设置里把显示方式切成「替换」。
  • 悬浮按钮偏小：可以在设置里关掉悬浮按钮，改用长按选中文本翻译。
  • AI 翻译需要填 Key：手机上粘贴 Key 不方便，建议先在桌面端配好，再用同步（如果该浏览器支持）。

四、还没覆盖的

Safari（iOS/iPadOS）需要 App Store 上架和 Apple 开发者账号，目前没有计划；系统级「翻译整个 App」不在浏览器扩展的能力范围内。
