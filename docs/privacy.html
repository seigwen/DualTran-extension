Privacy Policy

Last updated: 2026-11-10

DualTran is a browser extension that translates web pages and selected text. This page describes exactly what leaves your device, what stays on it, and who can see it.

Overview

DualTran keeps the original text on the page and shows the translation underneath it. There is no account, no sign-in, and no server operated by the developer. The extension talks to one kind of service only: the translation provider you have chosen, and only after you ask it to translate something.

In one sentence: nothing is collected about you, nothing is sent anywhere until you translate, and the only text that is sent is the text you chose to translate — going to the translation service you picked.

What the developer collects

Nothing.

  • No analytics. No page views, feature counters, or usage events are recorded.
  • No telemetry. The extension does not report how it is used, which sites you visit, or which languages you translate.
  • No crash reports. Errors stay in your browser's own console and are never uploaded.
  • No account system. There is nothing to register for and no user identifier to link data to.
  • No developer server. The developer does not operate any backend, relay, or proxy that receives your data. There is no endpoint the extension could report to.

What leaves your device

Data leaves your device in exactly one situation: you trigger a translation — by translating a selection, or by translating the page. When that happens:

  • Page text or selected text is sent to the translation service you selected. Only the segments being translated are sent — not your browsing history, not the whole page when you only translated a selection.
  • By default that service is Google Translate. Requests go to translate.googleapis.com, the public translation endpoint used by Google Translate, with no developer server in between.
  • If you configure an AI provider, the text is sent directly to that provider. OpenAI, Anthropic, Google Gemini, DeepSeek, Moonshot, Zhipu GLM, Qwen, Groq, OpenRouter, Ollama, LM Studio and 20+ other providers are supported. The request goes from your browser straight to the provider's API using your own API key — the key is never sent to the developer.

Nothing else is transmitted. The extension makes no other network requests: no background beacon, no usage ping, no remote configuration fetch, no advertising, and no tracking pixels.

What is stored

Everything the extension keeps stays on your machine, in your browser's extension storage. The developer has no copy of any of it.

  • Settings and translation preferences — target language, which engines are enabled, display mode, and per-site options.
  • Optional translation cache — if you turn caching on, recent translations are kept locally so repeated text does not have to be translated twice.
  • API keys — stored only in your browser's extension storage, and sent only to the provider they belong to, at the moment you translate with that provider.

Uninstalling the extension removes all of it. Nothing survives in a developer database, because there is no developer database.

Third parties

There is exactly one category of third party: the translation provider you chose.

  • That provider receives only the text you chose to translate, only at the moment you translate it.
  • It receives no account details from DualTran — there is no account. For AI providers it receives your own API key, which you supplied.
  • The provider's own privacy policy applies to that text and to how it is retained. For Google Translate that is Google's privacy policy; for an AI provider, the policy of that provider. Please read it before translating sensitive content.
  • No data is sold, rented, or shared with advertisers, data brokers, or any other party.
  • There are no other network requests, so there are no other third parties to disclose.
